# Java OOP Library System

## Overview
This project is a simple Java program that demonstrates important Object-Oriented Programming (OOP) concepts using a library example.



## Concepts Covered

- Encapsulation (using private variables and getters)
- Abstraction (using an abstract class)
- Inheritance (using extends)
- Method Overriding
- Polymorphism (using a parent class reference for child objects)
- ArrayList (dynamic storage of objects)
- User input (Scanner class)
- Exception handling (try-catch block)



## How It Works

- The system contains a base abstract class representing a general item.
- A specific class (Book) inherits from it.
- Multiple book objects are stored in a list.
- The user enters an index to select a book.
- The program displays the selected book name.
- If the user enters an invalid input or index, the program handles the error safely.


## Example Usage

1. Program displays available index range.
2. User enters a number.
3. Program shows the corresponding book.
4. If input is invalid, an error message is shown.



## Purpose

The purpose of this project is to practice and understand core Java OOP principles in a simple and practical way.
